# Дневник самопрограммирования

Личный веб-дневник по методике «10 минут в день» (Ася Тарасова): ежедневная
практика из 4 шагов, которая помогает отсеять навязанные сценарии и
удерживать фокус на своих целях.

Работает полностью локально в браузере — без бэкенда и регистрации, все
записи хранятся в `localStorage` этого браузера.

## Структура практики

1. **Разгрузка мыслей** — свободный текст, что накопилось в голове.
2. **Практика благодарности** — 5–10 пунктов, за что ты благодарна прямо сейчас.
3. **Дневник самопрограммирования** — 5 желаний в настоящем времени, как будто они уже сбылись.
4. **Действия на сегодня** — под каждым желанием конкретный шаг, который приближает к нему уже сегодня.

Дашборд отслеживает серию дней подряд (цель — 21 день) и показывает
настроение за месяц в виде теплокарты.

## Голосовой ввод

Рядом с каждым текстовым полем есть кнопка микрофона — она надиктовывает
текст через Web Speech API браузера (распознавание речи на русском).
Полноценно работает в Chrome/Edge; в браузерах без поддержки API кнопка
показывается неактивной, обычный набор текста при этом работает всегда.

## Запуск на Windows одним двойным кликом

Нужен установленный [Node.js](https://nodejs.org) — один раз.

- **`Дневник.vbs`** — основной способ запуска. При первом запуске откроется
  окно, где установятся необходимые компоненты (нужен интернет, займёт пару
  минут) — дождитесь его закрытия. При всех последующих запусках окно
  терминала не появляется вообще: сервер стартует в фоне и через пару секунд
  сам откроется браузер на `http://localhost:5173`.
- **`Запустить.bat`** — тот же запуск, но с видимым окном терминала (лог
  сервера). Полезно, если что-то не открывается и нужно увидеть ошибку.

Сервер сам следит, открыта ли вкладка с дневником: пока страница открыта, она
каждые пару секунд «даёт знать», что всё ещё используется. Как только вкладку
(или браузер) закрывают, сервер примерно через 10–15 секунд сам завершает
работу — вручную ничего останавливать не нужно, и папку проекта можно сразу
спокойно удалять/переносить. Если по какой-то причине сервер всё же остался
висеть — Диспетчер задач (Ctrl+Shift+Esc), найти `Node.js JavaScript Runtime`
и завершить процесс.

## Запуск на macOS

Нужен установленный [Node.js](https://nodejs.org) — один раз.

**Почему нельзя просто дважды кликнуть по файлу.** Любой файл-запускатель
(`.command`, и даже готовое приложение `.app`), *скачанный* из Telegram или
браузера, macOS помечает «карантином», и Gatekeeper блокирует его двойным
кликом («приложение повреждено» / «Apple не удалось подтвердить»). Это не
поломка файла — так macOS защищается от скачанных программ. Решается один раз.

### Настройка (делается однажды)

1. Откройте **Терминал** (`Cmd + Пробел`, наберите «Терминал», Enter).
2. Наберите `cd ` (со **знаком пробела в конце**), затем перетащите папку
   проекта из Finder прямо в окно Терминала — путь подставится сам. Нажмите Enter.
3. Наберите и выполните:
   ```bash
   bash "Установить-на-Mac.command"
   ```

Скрипт снимет «карантин» с папки, при первом запуске установит нужные
компоненты (нужен интернет, пару минут) и создаст на **рабочем столе** значок
**«Дневник»**.

### Дальше — просто двойной клик

Значок «Дневник» на рабочем столе создан **локально на вашем Mac**, поэтому
«карантина» на нём нет и Gatekeeper его не блокирует. Открывайте дневник
двойным кликом по нему — откроется браузер с дневником, Терминал больше не
нужен. (Голосовой ввод работает, потому что дневник открывается в обычном
браузере — Safari/Chrome.)

Останавливать сервер вручную не нужно: он сам завершает работу через 10–15
секунд после закрытия вкладки браузера.

**Запасной вариант.** После шага настройки начинает работать и файл
**`Запустить.command`** — по нему тоже можно запускать дневник двойным кликом
(откроется окно Терминала с логом сервера; на Mac это окно скрыть нельзя).

## Запуск вручную (Windows / macOS / Linux)

```bash
npm install
npm run dev
```

Откроется адрес из вывода Vite (обычно `http://localhost:5173`).

Для продакшен-сборки:

```bash
npm run build
npm run preview
```

## Стек

React + TypeScript + Vite + Tailwind CSS, без внешних зависимостей для
хранения данных — только `localStorage`.
